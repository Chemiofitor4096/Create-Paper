# 合成路线
### 粉碎
原木[1] -> 木纤维[4]
原木[1] -> 木屑[32]
### 搅拌
水 [250mB] + 碱性物质 [1] + 纸浆原材料 [1] -> 纸浆（物品） [1]  
水 [250mB] + 碱性物质 [1] + 木屑 [8] -> 纸浆（物品） [1]  
水 [1000mB] + 纸浆（物品） [2] -> 纸浆（流体） [1000mB]
### 打浆
水 [1000mB] + 碱性物质 [1] + 纸浆原材料 [2] -> 纸浆（流体） [1000mB]  
### 抄纸
纸浆（流体） [250mB] -> 粗湿纸 [1] （抄纸台）  
纸浆（流体） [1/3桶] -> 粗湿纸 [1] （炼药锅）
### 烟熏
粗湿纸 [1] -> 粗纸 [1]
### 洗涤
粗纸 [1] -> 粗湿纸 [1]
### 冲压
纸浆（物品） [1] -> 粗纸 [1] （抄纸台）  
纸浆（物品） [2] -> 75% 粗纸 [2] + 25% 废纸 [2] （工作盆）  
粗湿纸 [2] -> 纸板 [1] （工作盆）
粗纸 [2] -> 75% 纸板 [1] + 25% 废纸 [2] （工作盆）
